# Release handoff checklist

- [ ] Exact candidate commit/digest and required QA approval recorded.
- [ ] Staging configuration and synthetic-data UAT checked.
- [ ] Backup, migration rehearsal and recovery strategy documented.
- [ ] Secrets and least-privilege configuration verified without disclosure.
- [ ] Monitoring, smoke checks and rollback triggers assigned.
- [ ] Owner explicitly approves exact production operation separately.

This skill prepares the packet; it does not itself authorize or execute production changes.
