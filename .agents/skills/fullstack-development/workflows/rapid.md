# Rapid mode

Bounded prototype, component or fix. Record baseline, acceptance checks and scope; use only relevant specialists; run targeted regression checks. Mark skipped phases N/A with reasons; high-risk changes cannot bypass required QA.

Follow `../references/workflows.md` for lifecycle and `../quality-gates/gates.md` for gate decisions. Choose scope FULL, FEATURE, REDESIGN, COMPONENT or FIX separately. Do not infer deployment permission.
