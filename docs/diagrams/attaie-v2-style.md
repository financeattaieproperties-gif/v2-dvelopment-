Project-local style selected by owner approval to refine Variant 1. Installed diagram-design defaults remain untouched.

|---|---|

Use dark ink for text on light green/slate fills. English planning labels, no shadows or gradients. Orthogonal connectors, explicit receiving department, maximum eight process nodes per diagram. Architecture shows trust boundaries; swimlanes show handoffs. All proposals must be labelled; no data or claims of deployed behavior.
