# DevOS V4 local runtime design
Decision: Python stdlib + SQLite + loopback Studio; Codex CLI adapter, fixture adapter. No external hosting, no auto deployment. New isolated workspace per project; never import existing code automatically. Sequential role sessions avoid conflicting writes; real CLI sessions are separate contexts, not simultaneous subagents. Scope and design approvals are explicit; release is handoff only. Owner-configured verification argv runs local code only after scope approval. Treat code/workspace and model text as untrusted; keep logs local; inspect CLI sandbox/MCP configuration before using real mode. Fixture demonstrates orchestration only. No API subscription assumed. Test plan: red/green unit and integration tests, fake CLI contract test, HTTP/Studio smoke and browser if available; report blocked live provider. Default mode professional, landing or full stack profiles.
