# Professional mode

Default for substantial work. Establish product scope, architecture and contracts; route design and implementation specialists; integrate, test and request independent QA; prepare release packet and memory updates. Missing independent QA must be disclosed and blocks release readiness when required.

Follow `../references/workflows.md` for lifecycle and `../quality-gates/gates.md` for gate decisions. Choose scope FULL, FEATURE, REDESIGN, COMPONENT or FIX separately. Do not infer deployment permission.
